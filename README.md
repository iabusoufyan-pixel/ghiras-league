# دوري غراس

موقع الدوري: الترتيب، والمباريات، والهدافون، والتشكيلات، والتحديات، والخزينة، ومنشورات جاهزة للواتساب.

- **الطلاب:** يفتحون الرابط ويشاهدون فقط.
- **اللجنة:** تضغط "دخول اللجنة" وتكتب الرمز، ثم تُدخل النتائج من الجوال، فتظهر للجميع خلال ثوانٍ.

## محتويات المشروع

| الملف | وظيفته |
|---|---|
| `public/index.html` | صفحة الدوري كاملة |
| `api/state.js` | حفظ البيانات وقراءتها، والتحقق من رمز اللجنة |
| `seed.json` | بيانات البداية (نتائج الجولة الأولى، والتشكيلات، والتحديات) |
| `vercel.json` | إعدادات Vercel |

## النشر على Vercel (مرة واحدة، نحو ١٠ دقائق)

### ١) ارفع المشروع إلى GitHub

1. أنشئ حسابًا في github.com إن لم يكن لديك.
2. اضغط **New repository**، وسمّه `ghiras-league`، ثم اضغط **Create repository**.
3. اضغط **uploading an existing file**، واسحب **محتويات** مجلد المشروع بعد فك الضغط: مجلد `api`، ومجلد `public`، وبقية الملفات.
4. اضغط **Commit changes**.

### ٢) أنشئ المشروع في Vercel

1. ادخل vercel.com بحساب GitHub.
2. اضغط **Add New → Project**، واختر مستودع `ghiras-league`، ثم **Import**.
3. اترك الإعدادات كما هي، واضغط **Deploy**.

سيظهر لك رابط مثل `ghiras-league.vercel.app`. تفتح الصفحة الآن، لكن الحفظ لا يعمل بعد.

### ٣) اربط قاعدة البيانات (مجانية)

1. من صفحة المشروع في Vercel افتح تبويب **Storage**.
2. اختر **Upstash** (Redis)، ثم **Create**، واختر الخطة المجانية.
3. اربطها بمشروع `ghiras-league`.

يضيف Vercel مفاتيح الاتصال بنفسه، فلا تحتاج إلى نسخ أي شيء.

### ٤) ضع رمز اللجنة

1. افتح **Settings → Environment Variables**.
2. أضف متغيرًا اسمه `COMMITTEE_PIN`، وقيمته الرمز الذي تختاره، مثل `Ghiras-2026`.
   اجعله ٨ خانات على الأقل، ولا تنشره إلا لأعضاء اللجنة.
3. احفظ.

### ٥) أعد النشر

افتح تبويب **Deployments**، ثم من القائمة بجانب آخر نشر اختر **Redeploy**.

**انتهى.** افتح الرابط، واضغط "دخول اللجنة"، واكتب الرمز. أول حفظ تقوم به يخزّن بيانات الجولة الأولى في قاعدة البيانات.

## أسئلة متوقعة

**ظهرت رسالة "قاعدة البيانات غير مربوطة بعد"؟**
لم تكتمل الخطوة ٣، أو لم تُعِد النشر بعد الربط (الخطوة ٥).

**ظهرت رسالة "الرمز غير صحيح"؟**
تأكد من قيمة `COMMITTEE_PIN`، وأنك أعدت النشر بعد إضافته. بعد ١٠ محاولات خاطئة يُوقَف الدخول ربع ساعة.

**حفظ عضوان في اللحظة نفسها؟**
يُعتمد الأسبق، ويظهر للآخر تنبيه بإعادة إدخال تعديله، فلا يضيع تعديل الأول.

**أريد تغيير رمز اللجنة؟**
غيّر قيمة `COMMITTEE_PIN`، ثم أعد النشر. يخرج كل من دخل بالرمز القديم تلقائيًا عند أول حفظ.

**أريد اسم نطاق خاصًا (مثل ghiras.sa)؟**
من **Settings → Domains** في Vercel.
